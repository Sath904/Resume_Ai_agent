# Resume AI Interview Coach

## Overview
This project is an AI Interview Coach that generates mock interview conversations based on a candidate's resume and the desired job role.  
The backend uses **FastAPI** and the **pydantic_ai** agent, while the frontend is a **React** app with a modern, doodle-styled UI.

## Features
- Paste your resume and desired job role.
- Generate a full interview conversation.
- Professional and interactive frontend UI.
- Uses AI to simulate interviewer questions based on resume and role.
